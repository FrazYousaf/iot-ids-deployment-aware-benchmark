# Paper Results Mapping

This file explains how the notebooks correspond to the paper experiments.

## Notebook-to-Experiment Mapping

| Paper Experiment | Notebook |
|---|---|
| CIC-IoT 2023 benchmark | `notebooks/01_CIC_IoT_2023.ipynb` |
| CIC-IoT-IDAD 2024 benchmark | `notebooks/02_CIC_IoT_IDAD_2024.ipynb` |
| TabularIoTAttack-2024 benchmark | `notebooks/03_TabularIoTAttack_2024.ipynb` |
| DataSense CIC-IIoT 2025 benchmark | `notebooks/04_DataSense_CIC_IIoT_2025.ipynb` |
| Merged CIC-IoT-IDAD 2024 + TabularIoTAttack-2024 benchmark | `notebooks/05_Merged_CIC_IDAD_TabularIoTAttack_2024.ipynb` |

## Full-Feature and Reduced-Feature Design

Each notebook evaluates the same model families under two settings:

1. Full-feature setting
2. Reduced-feature setting

The reduced-feature setting is used to evaluate whether similar intrusion-detection performance can be preserved with fewer features.

## Figure and Table Outputs

The notebooks generate final model-comparison tables, feature-importance outputs, classification reports, confusion matrices, and paper-ready plots where available.

If figures are not included in the repository, they can be regenerated by running the corresponding notebook.
